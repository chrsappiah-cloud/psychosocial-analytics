Psychosocial Analytics — App Review Notes (v1.0.0, build 4)

IMPORTANT: This build removes all in-app purchases and Apple Pay. The app is free. There are no StoreKit products, no Restore Purchases, and no payment UI.

Sign-in (required):
- Public Access tab: enter any email and optional display name → Sign In (clinician role).
- Administrator tab: admin@psychosocialanalytics.com / admin123 → full admin panel.

Admin panel (shield tab, administrator only):
- Overview: session and storage summary
- Access: assign role (Clinician / Administrator), access tier (Free / Professional / Enterprise), and active status. Tiers are not sold via the App Store.
- Storage: backend connection status (Supabase, iCloud, Cloudflare when configured)

Upload tab: files, photo/video library, pasted text, HTTPS URL import, New Client intake.

Assessments: structured sections; AI draft returns simulated narrative text for clinician review only. No PHI is sent to third-party AI in this build.

Account deletion (Guideline 5.1.1(v)):
- Settings → Account → Delete Account → confirm twice
- Permanently removes profile and all local assessments, clients, and uploads on this device

Export compliance: standard HTTPS/TLS only (ITSAppUsesNonExemptEncryption = false).

Contact: support@psychosocialanalytics.com
