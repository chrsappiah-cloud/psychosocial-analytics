# TestFlight — Version 1.0.0 (1)

## What to Test

- Tab navigation: Home, Assess, Clients, **Upload**, Insights, Reports, Settings
- **Upload → Files & Media**: pick a document or paste text
- **Upload → URL Import**: import a public HTTPS file link
- **Upload → New Client**: save a new client record
- Create a new assessment and complete psychosocial sections
- Generate an AI report draft and confirm notification feedback
- Settings → Subscription and Restore Purchases
- Settings → Administrator panel (after debug promotion)

## Known limitations

- Backend sync uses mock/staging endpoints in development
- AI drafts are simulated text for workflow validation
- Sample client data is bundled for demo purposes
